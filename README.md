# RecipeVault

A self-hosted, invite-only Progressive Web App for capturing and organizing recipes from any website. Clean, ad-free, and entirely under your control.

## What it does

- **Capture recipes from any URL** — paste a link or prefix any recipe URL with your domain to automatically extract title, ingredients, steps, times, and images
- **Edit after capture** — correct or refine what was extracted before saving
- **Organize with tags** — tag recipes and filter by tag in your library
- **Collections** — group recipes into named collections and share them with friends or family (Owner / Editor / Viewer roles)
- **No accounts sold, no ads** — invite-only registration via single-use links generated by the admin

## Tech stack

| Layer | Technology |
|-------|-----------|
| Backend | Node.js 24 + Express 5 + TypeScript |
| Frontend | React 19 + Chakra UI v3 + TanStack Query v5 |
| Database | PostgreSQL 16 (via Prisma ORM) |
| Auth | JWT (access token) + httpOnly refresh-token cookie |
| Deployment | Docker Compose |

## Setup

### 1. Prerequisites

- Docker and Docker Compose installed on your server
- A domain pointing at your server (for TLS, handled by your own nginx outside this repo)

### 2. Clone and configure

```bash
git clone <this-repo> recipevault
cd recipevault

cp .env.example .env
# Edit .env — set POSTGRES_PASSWORD, JWT_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD
```

**Minimum required changes in `.env`:**

| Variable | What to set |
|----------|-------------|
| `POSTGRES_PASSWORD` | A strong random password |
| `JWT_SECRET` | A random string ≥ 32 characters |
| `ADMIN_USERNAME` | Your chosen admin username |
| `ADMIN_PASSWORD` | A strong password (min 8 chars, 1 uppercase, 1 number) |

### 3. Build and start

```bash
docker compose up --build -d
```

The app will be available at `http://localhost:3000` (or your domain via nginx).

On first start, Prisma migrations run automatically before the server starts.

### 4. Create the first user

The admin has no account in the app — they only generate invite links.

1. Log in to the admin panel:

```bash
curl -X POST http://localhost:3000/api/admin/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"<ADMIN_USERNAME>","password":"<ADMIN_PASSWORD>"}'
# → {"token":"<admin-jwt>"}
```

2. Create an invite link:

```bash
curl -X POST http://localhost:3000/api/admin/invites \
  -H 'Authorization: Bearer <admin-jwt>' \
  -H 'Content-Type: application/json' \
  -d '{"description":"for Jane"}'
# → {"id":"...","token":"<invite-token>","description":"for Jane","used":false,...}
```

3. Share the registration URL with your friend:
   `https://yourdomain.com/register?token=<invite-token>`

### 5. Capture a recipe

**Method A — URL prefix (fastest):**
Navigate to `https://yourdomain.com/www.seriouseats.com/some-recipe` and you'll be redirected to the editor with the recipe pre-filled.

**Method B — Add Recipe page:**
Click "Add Recipe" in the nav, paste any recipe URL, and click "Capture Recipe".

## Updating

```bash
git pull
docker compose up --build -d
```

Prisma migrations run automatically on startup.

- `recipevault_pgdata` — the PostgreSQL database
- `recipevault_images` — uploaded recipe images
